# macOS profile

Appium Mac2 is the native macOS baseline. Discover exact Appium, Mac2, XCTest, macOS, Xcode, Accessibility, UIAutomation, and signing capabilities. Host security changes require separate authorization and are never ordinary bootstrap.

Run Mac2 UI control serialized within one dedicated session. Support declared `.app`, `.dmg`, and `.pkg` artifacts. Attach by exact bundle/application identity and control only declared windows, processes, menus, and named OS dialogs. Never use Finder or the desktop as an unrestricted automation root.
