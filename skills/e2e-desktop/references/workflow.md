# Desktop workflow

## Read-only discovery
Inspect repository instructions, application identity/kind, supported driver configuration, packages, dedicated targets/sessions, windows, owned processes, OS interactions, test data, and cleanup before changing Protocol state.

## Plan and generate
Persist one installed-application boundary, selected execution units, driver/target/session candidates, artifacts, lifecycle, interaction boundary, authorizations, evidence, and cleanup. Preserve an existing supported setup. Authorized bootstrap changes only desktop test dependencies, lockfiles, tests, fixtures, configuration, and dedicated test support. Generation ends `generated-unverified` and performs no live lifecycle.

## Verify and resume
Require the current manifest revision, selected check IDs, supported driver, explicit target, proven dedicated session, artifact, lifecycle, interaction scope, authorizations, and sanitization. Record the baseline envelope before mutation. Execute only selected checks. Cleanup and restoration run after success and every safe terminal failure. Resume never replays completed unsafe actions or update transitions.

## Repair
Repair only a current high-confidence `test-defect` within the explicit allowed paths and attempt budget, then return to selected verification. Cleanup failure blocks completion.
