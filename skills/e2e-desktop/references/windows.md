# Windows profile

NovaWindows through the Appium ecosystem is the native Windows greenfield baseline. Discover exact driver, Appium, Windows UI Automation, OS, developer, signing/publisher, package, and session capabilities.

Preserve existing Appium Windows/WinAppDriver only as a legacy capability-gated path. Never select it for greenfield bootstrap or infer support from its name. Support declared portable/installer `.exe`, `.msi`, and `.msix` artifacts.

Never enable arbitrary PowerShell, Explorer-root attachment, registry access, unscoped filesystem modification, insecure driver extensions, or machine-wide mutation without exact disposable-target authorization.
