# Desktop Protocol 2 usage

Use the bundled `scripts/e2e_protocol.py` and desktop-only extension catalog. Bind every desktop execution unit to one `e2e.desktop@1.0` record owned by `e2e-desktop`.

Persist plan/generate/verify/repair transitions, current revision, selected checks, attempts, evidence, actions, authorizations, and handoffs before reporting outcomes. Validate after every mutation. Unknown extensions remain preserved and immutable. Unsupported desktop versions create `extension-incompatible`; missing desktop capability creates `capability-unavailable`.
